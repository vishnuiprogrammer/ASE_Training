Chapter 01
What is the DOM?
The Document Object Model — the bridge between your HTML and JavaScript.

When a browser loads an HTML page, it parses the markup and builds a tree of objects in memory. This tree is the DOM. Every tag becomes a node; JavaScript can read and rewrite any node at any time, making the page dynamic without a reload.

Think of HTML as a recipe and the DOM as the cooked meal — the browser cooks the HTML into a live, editable object tree.

The Node Tree

document
└─ <html>
   ├─ <head>
   │  └─ <title>"My Page"</title>
   └─ <body>
      ├─ <h1 id="title">"Hello"</h1>
      └─ <p class="intro">"World"</p>
Node Types
Element, Text, Comment, Document

Entry point

Selecting Elements
Six ways to find elements — from ancient to modern.

The Modern Pair (use these)

// Returns FIRST matching element (or null)
const el = document.querySelector('#myId');
const el = document.querySelector('.card');
const el = document.querySelector('ul li:first-child');

// Returns NodeList of ALL matches
const els = document.querySelectorAll('p.intro');
els.forEach(el => console.log(el));

Legacy Selectors (still useful)

getElementById('id')       // fastest — direct lookup
getElementsByClassName('c') // live HTMLCollection
getElementsByTagName('div') // live HTMLCollection
getElementsByName('email') // used for form fields
Live vs Static: getElementsBy* returns a live collection — it updates automatically when the DOM changes. querySelectorAll returns a static snapshot. Choose deliberately.

Chapter 03
Reading & Writing Content
Get and set text, HTML, attributes, styles, and classes.

Text & HTML Content

const el = document.querySelector('#box');

// READ
el.textContent  // all text (safe — strips tags)
el.innerHTML    // raw HTML string (careful: XSS risk!)
el.innerText    // visible text only (respects CSS)

// WRITE
el.textContent = 'Safe text';
el.innerHTML   = '<strong>Bold!</strong>';

Attributes

el.getAttribute('href')
el.setAttribute('href', 'https://example.com')
el.removeAttribute('disabled')
el.hasAttribute('required')   // → true/false

// data-* attributes via dataset
el.dataset.userId   // reads data-user-id="…"
el.dataset.userId = '42';

Styles & Classes

// Inline style (camelCase)
el.style.backgroundColor = 'blue';
el.style.fontSize         = '18px';

// classList API (preferred!)
el.classList.add('active')
el.classList.remove('hidden')
el.classList.toggle('open')    // flip on/off
el.classList.contains('active') // → boolean
el.classList.replace('old','new')

Chapter 04
Creating & Deleting Elements
Build and destroy nodes dynamically — the core of dynamic UIs.

Creating Nodes

// 1. Create
const div = document.createElement('div');
div.textContent = 'Hello!';
div.className   = 'card';

// 2. Insert
parent.appendChild(div)         // at end
parent.prepend(div)             // at start
parent.insertBefore(div, ref)   // before ref node
ref.after(div)                   // modern: after ref
ref.before(div)                  // modern: before ref

innerHTML vs createElement

// Fast but risky (XSS if user data injected!)
container.innerHTML += `<li>${userInput}</li>`;

// Safe — XSS-proof, better performance for many nodes
const li = document.createElement('li');
li.textContent = userInput; // always safe
ul.appendChild(li);

Removing & Cloning

el.remove()                  // removes itself
parent.removeChild(child)    // parent removes child
const copy = el.cloneNode(true)  // deep clone

// Replace an element
oldEl.replaceWith(newEl);

// Empty a container fast
container.innerHTML = '';
// or
container.replaceChildren();

    Chapter 06
    Event Bubbling & Delegation
    How events travel up the DOM — and how to exploit it.

    Bubbling

    When you click a <button> inside a <div> inside <body>, the click event bubbles up — it fires on button, then div, then body, then document, then window.

    button
    →
    div
    →
    body
    →
    document
    →
    window

    Event Delegation

    Instead of attaching listeners to 1000 items, attach one listener to the parent and check e.target:

    // BAD: 1000 listeners
document.querySelectorAll('li').forEach(li =>
  li.addEventListener('click', handle)
);

// GOOD: 1 listener via delegation
document.querySelector('ul').addEventListener('click', (e) => {
  if (e.target.matches('li')) {
    handle(e.target);
  }
});
    Delegation also handles dynamically added items — elements added after the listener was registered are automatically covered.
    // Capture phase (top-down — opposite of bubbling)
el.addEventListener('click', handler, { capture: true });

// Fire only once
el.addEventListener('click', handler, { once: true });

// Stop bubbling
e.stopPropagation();

    Fetch API
    Get data from servers — JSON, text, files — all asynchronously.

    Basic GET Request

    fetch('https://api.example.com/users')
  .then(response => {
    // response.ok = true if status 200–299
    if (!response.ok) throw new Error(response.status);
    return response.json();  // parse JSON body
  })
  .then(data => console.log(data))
  .catch(err => console.error(err));

    POST with JSON Body

    fetch('/api/users', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Riya', age: 24 })
}).then(r => r.json());

    Chapter 09
    Async / Await
    Write asynchronous code that reads like synchronous code.

    The Same Fetch, Cleaner

    async function getUser(id) {
  try {
    const res  = await fetch(`/api/users/${id}`);
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    const user = await res.json();
    return user;
  } catch (err) {
    console.error('Failed:', err);
  }
}

    Parallel Requests

    // Sequential (slow — waits for each)
const user  = await fetch('/user').then(r=>r.json());
const posts = await fetch('/posts').then(r=>r.json());

// Parallel (fast — fires both at once)
const [user, posts] = await Promise.all([
  fetch('/user').then(r=>r.json()),
  fetch('/posts').then(r=>r.json()),
]);

    Promises Explained

    pending→ operation in progress
    fulfilled→ completed successfully → .then()
    rejected→ failed → .catch()
    // Create your own Promise
const delay = (ms) => new Promise(resolve =>
  setTimeout(resolve, ms)
);

await delay(2000); // pause 2 seconds
    Chapter 10
    Rendering API Data to the DOM
    The full loop: fetch → transform → render → update.

    The Pattern

    async function loadPosts() {
  // 1. Show loading state
  container.innerHTML = '<p>Loading…</p>';

  try {
    // 2. Fetch
    const res   = await fetch('/api/posts');
    const posts = await res.json();

    // 3. Render — template literal or createElement
    container.innerHTML = posts.map(p => `
      <div class="card">
        <h2>${p.title}</h2>
        <p>${p.body}</p>
      </div>
    `).join('');
  } catch {
    // 4. Error state
    container.innerHTML = '<p>Failed to load.</p>';
  }
}
    Never inject user-supplied data into innerHTML — use textContent or DOM methods to prevent XSS attacks.

    DocumentFragment (performance)

    // Build off-screen, then inject once
const frag = document.createDocumentFragment();

items.forEach(item => {
  const li = document.createElement('li');
  li.textContent = item.name;
  frag.appendChild(li);
});

ul.appendChild(frag); // one reflow only!
