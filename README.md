## 🚀 Getting Started

### Prerequisites
```
✅ Git installed (https://git-scm.com/)
✅ Code editor (VS Code recommended)
✅ Modern web browser (Chrome, Firefox, Safari, Edge)
✅ Internet connection
```

### Installation & Setup

#### Option 1: Clone Main Repository
```bash
# Clone the main repository
git clone https://github.com/vishnuiprogrammer/ASE_Training.git
cd ASE_Training

# View available branches
git branch -a

# Switch to desired branch
git checkout HTML+CSS          # For HTML+CSS projects
git checkout Bootstrap-5       # For Bootstrap projects
git checkout Javascript        # For JavaScript projects
```

#### Option 2: Clone Specific Branch
```bash
# Clone only HTML+CSS branch
git clone --branch "HTML+CSS" https://github.com/vishnuiprogrammer/ASE_Training.git

# Clone only Bootstrap-5 branch
git clone --branch Bootstrap-5 https://github.com/vishnuiprogrammer/ASE_Training.git

# Clone only Javascript branch
git clone --branch Javascript https://github.com/vishnuiprogrammer/ASE_Training.git
```

#### Option 3: Download as ZIP
1. Visit: https://github.com/vishnuiprogrammer/ASE_Training
2. Click "Code" → "Download ZIP"
3. Extract the ZIP file
4. Open in your code editor

### Running Projects

#### HTML + CSS Projects
```bash
cd ASE_Training
git checkout HTML+CSS

# Open any project in browser
cd AdminDashboard
open index.html  # macOS
start index.html # Windows
```

#### Bootstrap-5 Projects
```bash
cd ASE_Training
git checkout Bootstrap-5

cd IProgrammer_Company
open index.html
```

#### JavaScript Projects
```bash
cd ASE_Training
git checkout Javascript

# For projects with local files
cd TaskFocus
open index.html

```
